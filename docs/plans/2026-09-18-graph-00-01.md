# Nodilume GRAPH.00–GRAPH.01 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Una repository privata e una finestra Windows che mostri una scena 3D locale, con rotazione, movimento e focus.

**Architecture:** WPF ospita WebView2; C# invia una fixture sintetica tramite messaggi JSON versionati. TypeScript/Three.js disegna la scena e gestisce la camera; le risorse sono locali e il trasporto non espone oggetti host.

**Tech Stack:** .NET SDK 10.0.400, net10.0-windows, WebView2 1.0.4191.47, Node 24.19.0, npm 11.17.0, TypeScript 7.0.2, Three.js/@types 0.186.0, esbuild 0.28.2. Bloccare le dipendenze effettive in package-lock.json e packages.lock.json.

**Spec:** `docs/specs/graph-3d-design.md`

## Global Constraints

- Windows come unico sistema iniziale.
- Repository GitHub nuova e separata dal software OptionLab/QOE.
- C#/.NET e WPF per applicazione e logica; TypeScript/Three.js in WebView2 per la vista; SQLite locale per i dati.
- Contenuti e dati utente sono testo, mai codice eseguibile nel visualizzatore.
- Le risorse grafiche sono distribuite localmente con il programma.
- Il grafo funziona senza accesso a Internet una volta installati i runtime necessari.
- GRAPH.01 non certifica lo zoom semantico o prestazioni con centinaia di migliaia di nodi.

**Interfaces:**
- C# `DemoScene.Create()` restituisce envelope `{ version:1, type:"scene", mapId:"demo", revision:1, nodes:[{id,title,x,y,z,color}], links:[{source,target}] }`.
- Viewer invia `{version:1,type:"ready"}`; host risponde con la scena. Viewer risponde `{version:1,type:"rendered",nodeCount,linkCount}` dopo un frame.
- `focusPose(position:number[],target:number[],node:number[],distance:number)` restituisce `{position:number[],target:number[]}` preservando la direzione e gestendo camera coincidente.
- Host accetta solo messaggi da `https://nodilume.local/`; nessuna navigazione remota o nuova finestra.
